# The Missing Column

This repository contains the code, evaluation data, and derived results for *The Missing Column: Separating Content Recovery from Answer-Form Realization in Cross-Lingual Interventions* (EACL 2027).

```
01-code/    beacon package, experiment scripts (scripts/), and analyses of stored outputs (analysis/)
02-data/    the evaluation set (inputs/) and the result files the analyses read (results/)
```

## Contents

- `01-code/README.md`: setup, the experiment scripts, and the analyses of stored outputs, each mapped to the paper.
- `02-data/README.md`: the evaluation set and every result folder.
